# poc/

Earlier CLI exploration sketch for OwlWhisper — kept for historical reference.

This directory predates the current Fyne GUI under `cmd/fyne-gui/` and is **superseded** by it. The code here was the original single-file experiment used to validate the libp2p connection layer before the project was restructured around a typed protobuf protocol and a real desktop UI.

It is not built or imported by the rest of the codebase. The reason it remains in the repo is to preserve the project's actual development trajectory rather than retroactively cleaning it up.

See the top-level [README](../README.md) for context on why the project was halted.
