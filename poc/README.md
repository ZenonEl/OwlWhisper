# poc/

Earlier exploration sketch for OwlWhisper — kept for historical reference.

This directory predates the current layout under `cmd/`, `internal/`, and `pkg/` and is **superseded** by it. The file here (`poc.go`) was the original single-file experiment used to validate the connection layer before the project was restructured.

It is not built or imported by the rest of the codebase. The reason it remains in the repo is to preserve the project's actual development trajectory rather than retroactively cleaning it up.

See the top-level [README](../README.md) for context on why the project was halted.
